# Hobby Mart — Mini Skyline RC Drift Car

A responsive single-product storefront made with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. The image gallery, responsive mobile menu, scroll reveal, and subtle parallax work without a backend.

## WhatsApp
All contact buttons open WhatsApp at **+91 81118 11370** with a pre-filled enquiry message. This website intentionally has no Buy Now or Add to Cart button.

## Before publishing
- Confirm the product details, stock, delivery terms, and what is included in the box.
- The site currently uses the price ₹1,299.
- For a public website, upload the folder to static hosting such as GitHub Pages, Netlify, or Cloudflare Pages.
- Product photos are enhanced for color/contrast/sharpness, but the original background has not been artificially removed. The photos show the actual car.
- This is a front-end only website. It does not collect orders, store customer data, or process payments.
